Abstract

Robustness is a prerequisite for deploying Vision-Language-Action (VLA) policies beyond the conditions they were trained in. RoboTwin-Plus extends the RoboTwin 2.0 bimanual manipulation platform with a structured perturbation suite that follows the LIBERO-Plus taxonomy — seven perturbation dimensions spanning twenty-one sub-dimensions across object layout, background texture, lighting, camera viewpoint, robot initial state, language instruction, and sensor noise. Every perturbation is applied per episode through a single declarative configuration and is fully backward compatible: features activate only when their keys are present, so existing RoboTwin configs behave identically. The result is a reproducible protocol for measuring how a policy's success degrades — one clean baseline plus seven perturbation branches over all fifty tasks.

Usage

Quick start

Data collection uses a single command pattern. A GPU is required.

# bash collect_data.sh <task_name> <config_name> <gpu_id>

# Clean baseline — no perturbation
bash collect_data.sh beat_block_hammer demo_clean 0

# A perturbation branch, e.g. lighting (L1–L4)
bash collect_data.sh beat_block_hammer demo_light 0

Install with bash script/_install.sh, then download assets with bash script/_download_assets.sh. See the README for the full setup.
