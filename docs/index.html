Seven perturbation dimensions

Each dimension maps to a LIBERO-Plus category and is applied per-episode through a single YAML config. Features only activate when their keys are present, so upstream RoboTwin configs keep working unchanged.

Quick start

All data collection uses one command pattern. A GPU is required.

# bash collect_data.sh <task_name> <config_name> <gpu_id>

# Clean baseline (no perturbation)
bash collect_data.sh beat_block_hammer demo_clean 0

# A perturbation branch, e.g. lighting
bash collect_data.sh beat_block_hammer demo_light 0

Install with bash script/_install.sh then bash script/_download_assets.sh. See the README for details.
